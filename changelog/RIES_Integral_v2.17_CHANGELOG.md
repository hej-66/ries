# RIES 定积分版 v2.17 更新日志

> 目标：彻底修复手机端与低配电脑因性能差异导致的数值求积精度崩塌与连带闭式误判，同时新增用户自主精度选择（12 / 18 / 25 / 35 位）与「闭式搜索」总开关，并全面优化移动与桌面前端布局与引导。

## 一、手机端重大失误根因排查
- **壁钟（`Date.now()`）硬截断导致硬件相关性崩塌**：此前 `integral-hp.js` 与 `integral-core.js` 中多处内置 `650ms–2500ms` 墙钟超时熔断。同一道例题在桌面上足够跑完 25 位高精度，在性能较弱的手机 CPU 上却未及收敛就被强行中止且丢弃已完成层级并退回 `null`。
- **连锁退化反应**：HP 层被掐断后只能落回 Double/自适应 Simpson 的 `~11.8 位` 粗值；确定性 BigInt PSLQ 因 `<14.5 位` 硬门槛被跳过；同时 RIES 自身 `linearComboBudgetMs`（默认 `3000ms`）在慢设备上提前中断，把低位浮点巧合快照当作早期结果展示。

## 二、核心架构与性能修复
1. **求积预算硬件无关化与已完成层保护（`integral-hp.js`）**：
   - 将 `tanhSinh`、`expSinh`、`sinhSinh` 的收敛控制从短壁钟迁移为求值点数预算 `maxEvals`（`4500 / 9000`）与更高安全保险丝（`25000ms`），并拆分数学奇点中止（`mathAborted`）与预算耗尽（`budgetAborted`）——达到预算或保险丝时若已完整算完 `L >= 2` 层，完整保留上一完成层 `prev`（`aborted: false, budgetHit: true`），不再整段作废。
   - 对 Gauss-Legendre 节点生成与求积规则启用对称性折半计算，计算量减半。
   - 为 `integratePeriodicKinkExpTail` 引入动态工作精度、周期零点自适应预测加密与随尾翼幅值递减的 `GL32/24 → GL16 → GL8` 自适应降阶，显著缩短旗舰例题计算耗时（桌面 25 位档由 `~1.43s` 降至 `~0.5–0.6s`，手机同等计算量亦可稳定完成）。
   - `cvzAccel` 与 `integrateOsc` 按目标精度动态调整 Chebyshev/CVZ 工作精度与阶数，覆盖 35 位超深高精度档。
2. **后台 Web Worker 多线程求积 + 随时中止（`integral-worker.js`、`integral-glue.js`）**：
   - 将数值求积与确定性 BigInt PSLQ 移至独立后台 Worker 线程（`integral-worker.js?v=2.17`），彻底解除主线程 UI 冻结；受限环境（如直接 `file://` 打开单页）自动无缝降级回异步分帧主线程执行。
   - 新增「停止计算」控制，支持在运行期间立即终止 Worker 与 RIES。
3. **RIES 同构重复方程去重与阶段异常识别（`integral-glue.js`）**：
   - 新增 `riesEqDedupKey` 折叠如 `(9/x)=((7·e)+4)`、`(9/(x+0))=((7·e)+4)`、`-((9/x))=-((7·e)+4)` 等平凡等价重复行，并将无 PSLQ 命中时的 RIES 默认阶段预算适度放宽（`≥6000ms`），同时识别阶段提前中断快照给出清晰提示。

## 三、用户可控精度档位与纯数值开关（`index.html`、`integral-core.js`、`integral-pslq.js`、`integral-glue.js`）
- **四档可选目标数值精度**：`12 位（极速预览）`、`18 位（双精度快）`、`25 位（推荐）`、`35 位（超高精度）`；核心求积与 PSLQ 精度/层数/定标上限按档位自适应匹配（支持高达 35+ 位展示与 34 位 PSLQ 定标）。
- **「闭式搜索」总开关**：关闭后进入「纯数值模式」，仅输出定积分数值、保守误差 `±σ` 与发散/振荡诊断，跳过符号解、PSLQ 与 RIES 并隐藏下方闭式/RIES 区域；主按钮文案同步切换为「计算定积分」。
- **动态后果提示与折叠对比表**：切换档位或开关时通过 `#igGuide` 实时提示后果（例如在「12 位 + 开启闭式」时明确警告 PSLQ 已跳过且 Fail-Closed 难拦低位巧合），并补充桌面/手机端响应式栅格与表格不换行防裂行样式优化。
